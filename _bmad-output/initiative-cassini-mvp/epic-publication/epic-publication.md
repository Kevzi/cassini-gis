# Publication : installeurs, video, depot presentable

## Description

Rendre le travail trouvable et installable : installeurs pour les trois systèmes, vidéo de démo, et un dépôt qu'un inconnu peut comprendre et essayer.

## Outcome

Quelqu'un qui découvre Cassini peut l'installer et refaire la démo seul ; le signal est une première installation réussie par une personne extérieure au projet.

## Requirements

À compléter à l'inception de cet epic. La source est la spec de l'initiative,
`../spec-cassini-mvp/spec-cassini-mvp.md`, section Capabilities.

## Done when

1. Un installeur par système, Windows, macOS et Linux, produit automatiquement et téléchargeable depuis une release du dépôt.
2. Une vidéo de démo montre le scénario complet, de l'import au PDF.
3. Une personne extérieure installe et refait la démo en suivant la seule documentation du dépôt.
4. Les licences de toutes les dépendances livrées sont listées dans la release.

## Boundaries

Frontière par activité : l'empaquetage et la mise en ligne. Le README d'architecture est livré bien plus tôt, dans l'epic 1 ; cet epic porte la documentation d'installation et d'usage.
