Votre SIG, en français.
Sans réseau.

Cassini est l'interface en français d'un SIG qui fonctionne entièrement hors ligne : vous décrivez ce que vous voulez, il propose les opérations, vous les validez, il les exécute et les journalise.

C'est une extension pour QGIS, posée sur un moteur indépendant ; vos données restent sur votre poste et rien n'est envoyé sur le réseau.

Pourquoi Cassini

  • 100 % hors ligne

    L'IA tourne sur votre poste. Aucune fonction n'utilise le réseau : adapté aux postes isolés.

  • Vous gardez la main

    Chaque demande devient une suite d'opérations affichée étape par étape, que vous validez avant exécution.

  • Rejouable

    Tout est journalisé à côté du projet QGIS : une analyse se rejoue à l'identique.

  • Vos données, chez vous

    Vous apportez vos fichiers. Cassini ne les modifie jamais et n'en envoie aucun nulle part.

Installer en trois étapes

  1. QGIS

    Installez QGIS (version 3.44 ou plus récente), si ce n'est pas déjà fait.

  2. Le moteur et le modèle

    Lancez un installeur de Cassini ci-dessous : il pose le moteur et le modèle d'IA (modèle sur Hugging Face).

  3. L'extension

    Dans QGIS, installez l'extension Cassini depuis le gestionnaire d'extensions, puis ouvrez son panneau.
