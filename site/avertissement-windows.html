L'avertissement de Windows à l'ouverture de l'installeur

En ouvrant l'installeur de Cassini, Windows (SmartScreen) peut afficher « Windows a protégé votre ordinateur ». Ce message apparaît pour tout programme récent qui n'est pas encore signé par un éditeur reconnu ; il ne dit pas que Cassini est dangereux. La signature du programme viendra plus tard.

Pour continuer

  1. Dans la fenêtre bleue, cliquez sur « Informations complémentaires ».
  2. Cliquez sur « Exécuter quand même ».

Pour vérifier le fichier avant

Le manifeste de chaque version, manifeste.json, donne l'empreinte SHA-256 du moteur de Cassini ; l'installeur la vérifie lui-même et ne pose rien si elle ne correspond pas.
